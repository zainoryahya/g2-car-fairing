Fairing only moves control points, so the skin stays a degree-p B-spline: continuity class is unchanged, only the quality (waviness) improves. One tensor-product B-spline skin. With p=3 every interior knot line is C², so position, tangent plane and curvature all match across patch boundaries (G2). Switch to p=2 and watch the Mean H bands and comb envelopes break at the patch boundaries. Glass, lamps and grille are paint regions on the same skin.
